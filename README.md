# BST — AVL-дерево на C++

В проекте реализовано бинарное дерево поиска `BinaryTree<T>` с AVL-балансировкой. Для работы с деревом есть консольный пример и визуализатор на SFML. Тесты написаны с помощью GoogleTest.

Дерево хранит уникальные значения. После вставки и удаления балансировка выполняется автоматически.

## Техническое задание

### Назначение системы

Реализовать на C++ бинарное дерево поиска с автоматической AVL-балансировкой. Система предназначена для хранения уникальных элементов, выполнения операций над деревом и демонстрации его работы. Основной интерактивный интерфейс — визуализатор на SFML; консольный пример выводит результат обхода заранее заданного дерева.

### Сущности и связи

- **`BinaryTree<T>`** хранит корень дерева и количество узлов, выполняет операции и управляет временем жизни узлов. Параметр `T` — тип хранимого значения.
- **Узел дерева** содержит значение, высоту и указатели на левого и правого потомков и родителя. Потомки образуют поддеревья; ссылки на родителей позволяют перемещаться вверх. В дереве поиска значения слева меньше значения узла, а справа — больше.
- **`IEnumerable<T>`** задаёт интерфейс получения перечислителя. `BinaryTree<T>` реализует его и создаёт `TreeEnumerator`.
- **`IEnumerator<T>`** задаёт операции перечислителя `HasNext` и `Next`. `TreeEnumerator` реализует этот интерфейс и хранит текущую позицию обхода. Перечислитель не владеет узлами; дерево должно существовать во время его использования.
- **`Stack<T>`** хранит данные в `DynamicArray<T>` и используется деревом для итеративного обхода и операций `Map`, `Where`, `Reduce`.
- **Визуализатор** создаёт дерево целых чисел, отображает его узлы и связи, передаёт дереву команды пользователя и использует перечислитель для подсветки обхода.
- **Модульные тесты** создают экземпляры дерева и стека и проверяют результаты операций и граничные случаи.

### Функциональные требования

1. Хранить уникальные значения и поддерживать вставку, поиск, удаление и очистку дерева. При повторной вставке существующего значения состав дерева не меняется.
2. После вставки и удаления поддерживать AVL-балансировку с помощью поворотов и обновления высот узлов.
3. Предоставлять обход по возрастанию через перечислитель, проверку наличия следующего элемента и получение следующего значения.
4. Поддерживать копирование и перемещение дерева, а также получение размера и проверку пустоты.
5. Предоставлять `Map`, `Where`, `Reduce`, извлечение копии поддерева и проверку вхождения поддерева с учётом значений и структуры.
6. Сохранять дерево целых чисел в строку и восстанавливать его из строки заданного формата, сохраняя форму дерева.
7. В визуализаторе отображать дерево, принимать целые числа для вставки и удаления и последовательно подсвечивать элементы обхода.
8. Покрыть основные операции модульными тестами и предусмотреть обработку некорректных входных данных с помощью исключений.

### Нефункциональные требования

- **Язык и структура:** C++20, шаблонные классы и динамические узлы на указателях. Для операций поиска тип значения должен поддерживать необходимые сравнения; отдельные методы могут предъявлять дополнительные требования к типу.
- **Корректность и память:** при операциях над деревом должны сохраняться его порядок, согласованность связей и AVL-баланс; динамическая память должна освобождаться. Пользователь освобождает перечислитель, возвращённый `GetEnumerator()`.
- **Проверяемость:** сборка и запуск тестов через Makefile и GoogleTest; поведение операций должно быть воспроизводимым.
- **Интерфейс:** управление с клавиатуры и отображение дерева через SFML 3; запуск визуализатора из корня проекта для загрузки шрифта.
- **Производительность:** провести замеры времени алгоритмов на объёмах порядка 10⁴–10⁵ и 10⁶–10⁸ элементов и построить график зависимости времени от числа элементов. **Замеры и график запланированы и пока не представлены.**

Описанные требования задают целевое поведение. Обработка некорректных строк при восстановлении дерева пока неполна: некоторые ошибочные записи могут приниматься или приводить к аварийному завершению и утечке памяти. Текущий строковый формат предназначен для `BinaryTree<int>`.

## Что реализовано

- Вставка, удаление, поиск и очистка дерева.
- Копирование и перемещение.
- Обход по возрастанию через `TreeEnumerator` и интерфейсы `IEnumerable` / `IEnumerator`.
- Преобразование `Map`, фильтрация `Where` и свёртка `Reduce`.
- Извлечение поддерева и проверка, содержится ли оно в другом дереве.
- Сохранение дерева в строку и восстановление из неё для `BinaryTree<int>`.
- Визуализация дерева, добавление и удаление чисел с клавиатуры.
- Собственный `Stack<T>`

## Управление визуализатором

| Клавиша | Действие |
| --- | --- |
| `I` | Перейти к вводу числа для вставки |
| `D` | Перейти к вводу числа для удаления |
| `0`–`9` | Ввести цифры |
| `-` | Добавить минус в начале числа |
| `Backspace` | Удалить последний символ |
| `Enter` | Подтвердить ввод |
| `Escape` | Отменить ввод |
| `Space` | Подсветить следующий элемент обхода |

`I`, `D` и `Space` работают, когда ввод числа не активен. Для завершения программы нужно закрыть окно.

Например, чтобы добавить 25, нажмите `I`, введите `25` и нажмите `Enter`. Для удаления 30 — `D`, `30`, `Enter`.

Пробел перебирает значения по возрастанию. После успешной вставки или удаления подсветка сбрасывается и обход начинается заново.

## Основные методы

Для подключения дерева нужен заголовок `BinaryTree.hpp` из папки `include`.

| Метод | Описание |
| --- | --- |
| `Insert(value)` | Добавляет значение; повторная вставка ничего не меняет |
| `Remove(value)` | Удаляет значение; если оно отсутствует, выбрасывает `std::logic_error` |
| `Find(value)` | Возвращает указатель на узел или `nullptr` |
| `Contains(value)` | Проверяет наличие значения |
| `GetSize()` | Возвращает количество узлов |
| `IsEmpty()` | Проверяет, пустое ли дерево |
| `Clear()` | Удаляет все узлы |
| `GetRoot()` | Возвращает указатель на корень |
| `GetHeight(node)` | Возвращает высоту узла: у листа `0`, у `nullptr` — `-1` |
| `GetBalanceFactor(node)` | Возвращает разность высот левого и правого поддеревьев |
| `GetEnumerator()` | Создаёт перечислитель для обхода по возрастанию |
| `InorderedTreeWalkIterative(node)` | Выводит значения поддерева по возрастанию в `std::cout` |
| `Map(func)` | Создаёт дерево преобразованных значений; одинаковые результаты объединяются |
| `Where(predicate)` | Создаёт дерево из значений, для которых предикат возвращает `true` |
| `Reduce(func, initial)` | Сворачивает значения по возрастанию, начиная с `initial` |
| `ExtractSubtree(node)` | Создаёт независимую копию поддерева |
| `ContainsSubtree(other)` | Проверяет совпадение значений и структуры поддерева |
| `ToString()` | Возвращает строковое представление дерева |
| `FromString(str)` | Возвращает новое дерево из строки |

Копирование дерева создаёт отдельные узлы. При перемещении узлы передаются новому дереву, а исходное становится пустым.

`Map`, `Where` и `Reduce` принимают указатели на функции следующих типов:

```cpp
T func(const T&);              // Map
bool predicate(const T&);      // Where
T func(const T& element, T accumulator); // Reduce
```

Можно использовать обычные функции или лямбды без захвата с подходящей сигнатурой.

### Пример использования

```cpp
#include <iostream>
#include <string>
#include "BinaryTree.hpp"

int main() {
    BinaryTree<int> tree;
    tree.Insert(20);
    tree.Insert(10);
    tree.Insert(30);
    tree.Insert(20); // Дубликат: размер остаётся равным 3.

    auto* it = tree.GetEnumerator();
    while (it->HasNext()) {
        std::cout << it->Next() << ' '; // 10 20 30
    }
    delete it;
    std::cout << '\n';

    auto doubled = tree.Map(+[](const int& x) -> int { return x * 2; });
    auto selected = tree.Where(+[](const int& x) -> bool { return x >= 20; });
    int sum = tree.Reduce(+[](const int& x, int acc) -> int {
        return acc + x;
    }, 0); // 60

    auto subtree = tree.ExtractSubtree(tree.Find(10));
    bool containsSubtree = tree.ContainsSubtree(subtree); // true

    std::string text = tree.ToString(); // "20(10(#,#),30(#,#))"
    auto restored = tree.FromString(text);

    std::cout << doubled.GetSize() << ' ' << selected.GetSize() << ' '
              << sum << ' ' << containsSubtree << ' '
              << restored.ToString() << '\n';

    tree.Remove(20);
}
```


### Перечислитель

`HasNext()` проверяет, остались ли элементы. `Next()` возвращает `const T&` на очередное значение и продвигает перечислитель. После конца обхода `Next()` выбрасывает `std::out_of_range`.

Перечислитель переходит между узлами через ссылки на детей и родителей. `GetEnumerator()` создаёт перечислитель в динамической памяти и возвращает `IEnumerator<T>*`; после использования вызывающая сторона должна выполнить `delete`. После изменения дерева для нового обхода нужно удалить старый перечислитель и снова вызвать `GetEnumerator()`. Само дерево должно существовать всё время работы перечислителя.

### Формат строки

Узел записывается как `значение(левое_поддерево,правое_поддерево)`, пустое поддерево обозначается `#`:

```text
#
10(#,#)
20(10(#,#),30(#,#))
```

Строка сохраняет значения и форму дерева. Для восстановления передайте результат `ToString()` в `FromString()` через переменную `std::string`. Метод возвращает новое дерево:

```cpp
std::string str = tree.ToString();
auto restored = tree.FromString(str);
```
